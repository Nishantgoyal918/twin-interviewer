## Deployed (2026-11-02)

- Live: https://twin-interviewer-pi.vercel.app (creator: `/creator`; design pages: `/design-doc`,
  `/design-doc-v2`, `/design-doc/full`)
- Vercel project `twin-interviewer` (Hobby), functions in Mumbai (`bom1`). Supabase (free,
  Mumbai: Postgres + pgvector, auth, private `audio` bucket), Upstash Redis (free, Mumbai,
  auto-upgrade off) and QStash (free, Frankfurt) were added as Vercel Marketplace
  integrations; their keys live in the project's env. Migrations 0001–0003 applied.
- Deploy: `npx vercel deploy --prod` from `twin-interviewer/`. `/design-doc` and
  `/design-doc-v2` are hand-written HTML; `/design-doc/full` is generated by
  `uv run python scripts/build_design_doc.py`, so rerun that first if its sources changed.
- New pages need a route in `app/main.py` (local) and a rewrite in `vercel.json` (Vercel).
- The simulator is off in production. To run it there, set `SIM_KEY` in Vercel, redeploy,
  open `/dev/sim?key=…`; remove the key and redeploy afterwards.
- Vercel runs `app/main.py` with its FastAPI preset; don't add an `/api` rewrite (it hides the
  real path from the app).
- Spend: global $5/day breaker plus per-twin limits (config.yaml `caps`).

- Production Kavya and Venkat: energy ~8.8/10 but only 3/5 brief topics. Found:

  the planner goes breadth first, bridges after 3 engaged turns, drops goals after 90 s

  that open with a story question; fragments never read as flat; headline scorecard row
